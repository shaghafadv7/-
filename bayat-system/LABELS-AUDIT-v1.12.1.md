# مراجعة التسميات وسجل الأخطاء — v1.12.1

تاريخ المراجعة: 2026-08-26
سبب المراجعة: بلاغ من المستخدم — صف «إجمالي المدفوع (العربون + الدفعة الإضافية)» كان يعرض **1,000** بينما 1,000 هي **المتبقي** وليست المدفوع.

---

## 1) سجل الأخطاء المكتشفة

### خطأ رقم 1 — حرج ⚠️ (البلاغ الأصلي)

**الموقع:** `public/app.js` — نموذج «تحويل الحجز إلى بيع» / «تسجيل البيع»

**الوصف:** صف واحد (`id="calcRemain"`) كان يُستخدم لغرضين متناقضين بتسميتين مختلفتين حسب الحالة:

```js
// الكود الخاطئ
<span>${converting ? 'إجمالي المدفوع (العربون + الدفعة الإضافية)' : 'المتبقي بعد الدفعة'}</span>
<b id="calcRemain">0</b>
...
set('calcRemain', remaining);   // ← القيمة المحقونة هي «المتبقي» دائمًا
```

**النتيجة:** في وضع تحويل الحجز، التسمية تقول «إجمالي المدفوع» والقيمة المعروضة هي **المتبقي**.

**التحقق العددي من لقطة شاشتك:**

| البند | القيمة |
|------|--------|
| السعر النهائي | 500,000 |
| العربون المدفوع سابقًا | 9,000 |
| الدفعة الإضافية المدخلة | 490,000 |
| **إجمالي المدفوع الصحيح** | **499,000** |
| **المتبقي على العميل الصحيح** | **1,000** ← هذا ما كان معروضًا |
| صافي الربح | 489,000 (= 499,000 − 10,000 عمولة) ✔ يطابق اللقطة |

الرقم 489,000 في اللقطة يثبت أن **الحساب الداخلي كان سليمًا** (استخدم 499,000 مدفوع)، والخلل في **التسمية والعرض فقط** — لم تتأثر أي قيمة مخزّنة في قاعدة البيانات.

**الإصلاح:** فُصل الصف إلى صفين مستقلين:

```js
<div class="kv-money"><span>إجمالي المدفوع (العربون + الدفعة الإضافية)</span><b id="calcPaid">…</b></div>
<div class="kv-money"><span>المتبقي على العميل</span><b id="calcRemain">…</b></div>
...
set('calcPaid', totalPaid);    // إجمالي المدفوع
set('calcRemain', remaining);  // المتبقي على العميل
```

كما حُذف التعليق الميت `if (deposit > 0 && g('calcRemain')) { /* أعد تسمية الصف… */ }` الذي يكشف أن المطور السابق **كان يعلم بالمشكلة ولم يكملها**.

### خطأ رقم 2 — متوسط
**الموقع:** `public/app.js` — جدولا العمولات (موضعان)
**الوصف:** أعمدة `<th>العمولة</th><th>المدفوع</th><th>المتبقي</th>` تعرض `commission_paid` و`commission_due`، لكن التسمية العامة «المدفوع/المتبقي» تُقرأ طبيعيًا على أنها مدفوعات **العميل** لا **المسوق**.
**الإصلاح:** «العمولة المستحقة / المدفوع للمسوق / المتبقي للمسوق».

### خطأ رقم 3 — متوسط
**الموقع:** `lib/excel.js`
**الوصف:** عمودان مختلفان بمعنى شبه متطابق: «المتبقي» (`remaining_amount`، قد يكون سالبًا عند الدفع الزائد) و«المبالغ المتبقية» (`receivable`، الموجب فقط) — لا يمكن للمستخدم التفريق بينهما.
**الإصلاح:** «المتبقي على العميل» و«الذمم غير المحصلة».

### خطأ رقم 4 — تسميات متعددة لنفس المفهوم
سبع صيغ لـ«صافي الربح»، عشر لـ«السعر النهائي»، وست لـ«إجمالي المدفوع» موزعة بين الشاشة وPDF وExcel. وُحّدت كلها.

## 2) معجم التسميات المعتمد (المرجع الوحيد)

يُمنع استخدام أي مرادف خارج هذا الجدول:

| المصطلح المعتمد | التعريف الدقيق | الحقل في المحرك |
|----------------|----------------|-----------------|
| **قيمة العقار** / السعر الأساسي | سعر الوحدة قبل أي خصم | `base` |
| **الخصومات** | مجموع بنود الخصم النشطة | `discounts` |
| **السعر النهائي** | قيمة العقار − الخصومات + التسويات | `final` |
| **العربون المدفوع سابقًا** | دفعات الحجز المربوطة بالصفقة | `paid_deposit` |
| **إجمالي المدفوع** | العربون + الدفعات المحصّلة فعليًا | `paid` |
| **المتبقي على العميل** | السعر النهائي − إجمالي المدفوع | `remaining` |
| **رصيد مستحق للعميل** | الزائد عن السعر النهائي (لا يدخل الأرباح) | `client_credit` |
| **الذمم غير المحصلة** | المتبقي الموجب فقط (للتقارير المجمّعة) | `receivable` |
| **الإيراد المحقق** | min(المدفوع، السعر النهائي) | `realized_revenue` |
| **عمولة المسوق** | العمولة المستحقة على الصفقة | `commission` |
| **المدفوع للمسوق** | ما صُرف فعليًا من العمولة | `commission_paid` |
| **المتبقي للمسوق** | العمولة − المدفوع للمسوق | `commission_remaining` |
| **المصروفات** | مصروفات الصفقة النشطة | `expenses` |
| **صافي الربح** | الإيراد المحقق − التكلفة − العمولة − المصروفات | `net_profit` |

### قواعد إلزامية
1. **التسمية تصف القيمة المعروضة حرفيًا** — يمنع أن يعرض حقل «المدفوع» قيمة «المتبقي».
2. **لا صف واحد بتسميتين متغيرتين** — إن اختلف المعنى فصفّان منفصلان.
3. «المدفوع/المتبقي» **مجرّدة ممنوعة** في سياق العمولات — تُقيَّد دائمًا بـ«للمسوق».
4. المصطلح الواحد **لا يتغير** بين الشاشة وPDF وExcel.

## 4) الاختبارات

أُضيفت **7 اختبارات تسميات** (18–24) في `scripts/test-ui-v1.12.js` تعيد إنتاج حالة البلاغ حرفيًا:

```
✓ 18. يوجد صف مستقل لإجمالي المدفوع
✓ 19. «إجمالي المدفوع» يعرض المدفوع فعلاً (499000 = عربون 9000 + إضافي 490000)
✓ 20. «المتبقي على العميل» يعرض المتبقي فعلاً (1000)
✓ 21. السعر النهائي = المدفوع + المتبقي (500000 = 499000 + 1000)
✓ 22. لا يعرض الحقلان نفس القيمة (كشف الخلط بين المدفوع والمتبقي)
✓ 23. تسمية «المتبقي على العميل» موجودة
✓ 24. أُزيلت التسمية القديمة الملتبسة
```

الاختبار 22 هو **الحارس الدائم**: لو عاد أي حقل ليعرض قيمة حقل آخر، يفشل فورًا.
